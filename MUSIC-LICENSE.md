# Musik Invitalab

Project ini memakai satu musik bersama: `katalog/musik/invitalab-ambient.mp3`.

Audio tersebut dibuat khusus untuk project Invitalab sebagai instrumental ambient sintetis dan tidak mengambil sampel dari rekaman lagu pihak ketiga. File lagu komersial yang sebelumnya dipakai sebagai demo sudah dikeluarkan dari project agar paket tidak bergantung pada izin yang belum dimiliki.

Jika musik diganti, gunakan karya milik sendiri atau simpan bukti lisensi tertulis yang secara jelas mengizinkan penggunaan komersial, distribusi melalui website pelanggan, dan penyimpanan file audio pada hosting Invitalab.

Dasar pemeriksaan: UU Nomor 28 Tahun 2014 tentang Hak Cipta dan PP Nomor 56 Tahun 2021 tentang Pengelolaan Royalti Hak Cipta Lagu dan/atau Musik.
